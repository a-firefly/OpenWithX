# 03: 外接磁盘与生命周期下持续可用

**What to build:** 本地外接磁盘挂载后，其普通目标文件夹自动获得 Finder 菜单覆盖；卸载后更新范围，重新挂载无需配置。扩展冷启动与系统重启后自动恢复覆盖和配置，主应用无需常驻。

**Blocked by:** 02 — 从 Finder 打开本地目标文件夹。

**Status:** ready-for-agent

- [ ] 本地外接磁盘已挂载时自动覆盖普通文件夹及嵌套目录，并可通过一级菜单交给 VS Code 打开。
- [ ] 新磁盘挂载、卸载及重新挂载时自动更新当前范围，无需重选目录或启动配置界面。
- [ ] 外接磁盘断开后不再作为当前可用目标；打开过程中的断开错误由统一错误恢复流程处理。
- [ ] 主应用退出、扩展冷启动及系统重启后，自动恢复当前可用磁盘的覆盖和已保存配置。
- [ ] 网络卷、云盘及特殊虚拟位置不计为已支持范围，继续遵守普通文件夹单选与特殊对象排除规则。
- [ ] 按 TDD 验证可测试的范围与生命周期逻辑，并实测挂载、卸载、重新挂载、冷启动和重启；变化同步相关文档。
