# 02: 从 Finder 打开本地目标文件夹

**What to build:** 将验证通过的路线实现为最小可用产品：用户无需配置目录，即可在 Finder 右击本地单个普通目标文件夹，通过一级菜单交给自动发现的正式版 VS Code 打开，主应用退出后仍可使用。

**Blocked by:** None。01 已按调整后的核心可行性验收范围 resolved，当前任务可开始。

**Status:** ready-for-agent

- [ ] 自动覆盖内置磁盘的不同本地普通文件夹及嵌套目录，无需目录配置或预先目录授权；遵循任务 01 验证通过的集成与沙盒方案。
- [ ] 仅单选普通文件夹显示一级菜单；文件、多选、应用包、Finder 替身、符号链接及窗口空白处无本功能入口，不自动解析链接。
- [ ] 使用 NSWorkspace 自动发现正式版 VS Code，并以目标文件夹 URL 发起打开请求；不依赖 code 命令、PATH、终端或 shell。
- [ ] 中文、空格及嵌套路径正确打开；打开时激活 VS Code，窗口复用或新建遵循 VS Code 设置，不强制新进程或窗口。
