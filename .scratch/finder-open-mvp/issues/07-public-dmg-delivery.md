# 07: 完成本机自用安装与验收

**What to build:** 提供仅供当前用户本机自用的 Apple Silicon 构建，安装到“应用程序”，完成首次使用与日常打开验收。无需公开下载渠道，不强制制作 DMG；为会员到期后继续使用既有版本，自用交付采用 Developer ID Application 签名、安全时间戳、Apple 公证及附加票据，并拒绝嵌入 Provisioning Profile。日常开发仍保留原来的开发签名与配置。不要求干净权限环境，不保证其他用户正常使用。

**Blocked by:** 03 — 外接磁盘与生命周期下持续可用；06 — 完成无需终端和目录选择的首次配置。

**Status:** ready-for-human

- [x] 检查当前团队的 Developer ID Application 证书及私钥、公证凭证与主应用和扩展配置，记录可复现的构建和安装方式；缺少签名或公证条件时如实记录，不以开发构建替代长期自用交付。
- [x] 适用构建配置的最低系统版本调整并验证为 macOS 26.0，自用构建仅包含 Apple Silicon；主应用与扩展遵循已验证的沙盒和最小权限方案。
- [ ] 产出 Developer ID 签名、Hardened Runtime、安全时间戳、公证及附加票据的本机自用构建；核验主应用与内嵌扩展同团队、最小权限、无调试授权且不嵌入 Provisioning Profile，并在“应用程序”中的安装副本上验收；DMG 仅在便于本机保存或重装时按需制作。
- [x] 记录安装到“应用程序”、手动替换本机构建更新及支持范围的说明；不提供官网或 GitHub 公开下载，不自动检查更新，不要求 Mac App Store 上架。
- [ ] 在当前用户环境验证安装、扩展启用、无目录配置的首次使用、实际 Finder 打开、主应用退出、扩展冷启动和系统重启后的行为，并记录环境和结果。
- [ ] 回归中文及空格路径、非支持输入隐藏、多副本选择及失效、外接盘变化、重复点击、错误恢复和状态真实性；复核受保护位置与其他扩展共存的已验证边界。
- [ ] 检查不读取项目内容、不修改项目、不保存打开历史、不收集统计、不自动上传诊断，默认诊断避免完整项目路径；验证中英文与其他语言回退。
- [ ] 完成适合自用安装的检查及完整手动验收，修复发现的问题；可测试业务逻辑改动仍遵循 TDD，安装方式或架构决策变化同步相关文档。
