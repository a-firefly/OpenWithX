# 07: 交付可公开下载的 Apple Silicon DMG

**What to build:** 交付可通过官网或 GitHub 直接下载的 Developer ID 签名、Apple 公证的 Apple Silicon DMG，提供安装到“应用程序”的引导，并在当前用户环境完成首次使用与日常打开验收；不要求干净权限环境，不保证其他用户正常使用。

**Blocked by:** 03 — 外接磁盘与生命周期下持续可用；06 — 完成无需终端和目录选择的首次配置。

**Status:** ready-for-agent

- [ ] 检查开发者账号、证书及公开分发所需条件；缺少条件时明确记录阻塞，不将本机开发构建视为公开交付。
- [ ] 适用构建配置的最低系统版本调整并验证为 macOS 26.0，正式交付仅包含 Apple Silicon；主应用与扩展遵循已验证的沙盒和最小权限方案。
- [ ] 完成 Developer ID 签名、所需 Hardened Runtime 配置、Apple 公证及分发票据等发布校验，产出可分发 DMG。
- [ ] 提供安装到“应用程序”的引导、支持范围及手动下载更新说明；不自动检查更新，不要求 Mac App Store 上架。
- [ ] 在当前用户环境验证安装、扩展启用、无目录配置的首次使用、实际 Finder 打开、主应用退出、扩展冷启动和系统重启后的行为，并记录环境和结果。

- [ ] 检查不读取项目内容、不修改项目、不保存打开历史、不收集统计、不自动上传诊断，默认诊断避免完整项目路径；验证中英文与其他语言回退。
