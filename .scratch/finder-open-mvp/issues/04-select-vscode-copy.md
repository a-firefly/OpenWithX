# 04: 选择并持久使用指定的正式版 VS Code

**What to build:** 用户可重新检测正式版 VS Code，或手动固定一个正式版副本。选择和必要授权在本机持久保存，扩展使用该副本处理 Finder 打开请求；指定副本失效时要求重新选择。

**Blocked by:** 02 — 从 Finder 打开本地目标文件夹。

**Status:** ready-for-human

- [x] 提供重新检测与手动选择入口；未手动指定时使用系统发现的正式版副本，不承诺多副本固定自动排序。
- [x] 手动选择仅接受正式版 VS Code，拒绝 VS Code Insiders 及其他不支持的开发工具。
- [ ] 保存选择和必要应用授权，主应用退出、扩展重启及系统重启后仍能使用指定副本完成打开请求。
- [x] 指定副本移动、删除或不可用时明确要求重新选择，不静默切换到其他副本；与统一错误恢复流程的最终联验由任务 06 完成。
- [x] 未安装时提供官方下载入口，由用户主动打开网页，不自动安装。
- [ ] 按 TDD 验证发现、选择、持久化及失效规则，并实测跨进程授权与多副本场景；变化同步相关文档。
