# 06: 完成无需终端和目录选择的首次配置

**What to build:** 用户通过主应用完成 VS Code 检测或选择、Finder 扩展启用引导，以及一次手动 Finder 打开验证。主界面真实展示配置与验证状态，并作为日常故障排查入口。

**Blocked by:** 04 — 选择并持久使用指定的正式版 VS Code；05 — 打开失败可恢复，重复点击行为明确。

**Status:** ready-for-agent

- [ ] 完整首次使用流程无需终端或目录选择；展示 VS Code 状态、扩展启用状态及支持范围说明。
- [ ] 提供目标 macOS 系统设置中的手动启用扩展引导，不自动操作 Finder。
- [ ] 系统扩展启用状态与用户端到端验证分别呈现；引导用户手动右击本地普通文件夹完成实际打开验证，未验证时不声称菜单已验证可用。
- [ ] 联验自动发现、手动固定副本、指定副本失效、未安装、失败唤起和恢复操作，形成可完成的配置与排障流程。
- [ ] 配置完成后用户可退出主应用，无常驻 Dock 或菜单栏要求；正常 Finder 打开成功不激活配置界面。
- [ ] 界面跟随系统语言，简体中文菜单为“使用 VS Code 打开”，英文为“Open in VS Code”，其他语言回退英文；不提供应用内语言切换。
- [ ] 按 TDD 验证可测试的状态与流程逻辑，并手动验证首次配置、真实状态呈现和语言回退；变化同步相关文档。
