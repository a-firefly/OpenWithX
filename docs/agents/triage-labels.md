# Triage Labels

在本地 Issue 文件的 `Status:` 行中使用以下字符串。

| Canonical role | Tracker value | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交由自主代理实施 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不予处理 |

当技能提及某个分诊角色时，使用表中对应的 Tracker value。

如需调整用语，修改 Tracker value 列。
