# 采用用户所选目录的最小权限与沙盒优先策略

当前状态：2026-10-22 关于选择父目录并持久授权的流程已由 [ADR 0004](0004-automatic-local-folder-coverage.md) 取代，不再要求用户配置父目录。最小权限、不读取项目内容、不修改项目、无高权限要求与沙盒优先原则继续有效。以下保留原决策及其理由。

OpenWithX 仅请求用户所选项目父目录的必要只读访问，并持久保存所需授权；监控范围与文件访问授权分别处理。主应用和 Finder Sync 扩展优先保持沙盒，不读取项目文件内容、不修改项目，也不要求管理员、辅助功能或完全磁盘访问权限，以此换取明确配置范围内的能力，而非默认全盘覆盖。

直接分发允许其他沙盒组合，但不以关闭主应用沙盒作为默认解决方案。授权跨进程使用、跨重启恢复、应用选择授权以及主应用退出后的打开链路均需验证；如不能满足需求，应基于实测证据重新讨论，不静默扩大权限。授权失效时引导重新选择，外接磁盘暂时断开则保留配置。

参考：[Apple 沙盒文件访问](https://developer.apple.com/documentation/security/accessing-files-from-the-macos-app-sandbox)、[Apple DTS 对直接分发沙盒组合的说明](https://developer.apple.com/forums/thread/776568)。
